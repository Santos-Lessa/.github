# Santos Lessa GitHub Configuration

This repository contains shared GitHub configuration and organization level files for **Santos Lessa**.

## Structure

```text
.github/
├── profile/
│   └── README.md
├── assets/
│   └── logo.png
└── README.md
```

## Organization profile

The public GitHub organization profile is defined in:

```text
profile/README.md
```

GitHub automatically renders this file on the main Santos Lessa organization page.

## Assets

Shared visual assets used by the organization profile can be stored in:

```text
assets/
```

Keep organization branding consistent with the Santos Lessa visual identity.

When updating the organization profile:

1. Keep the public profile concise and professional.
